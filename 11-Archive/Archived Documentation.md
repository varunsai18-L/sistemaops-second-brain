## Documentation Archive Criteria

Documentation is moved to this archive when:
- Associated product, system, or process has been deprecated or retired
- Documentation has been superseded by newer versions
- Product or system is no longer supported or maintained
- Documentation is more than 2 years old and not identified as critical historical reference
- Equivalent information is available in current documentation

For detailed criteria, see [[Archive Policy]].

## How to Use This Index
Each archived documentation item includes:
- Document title and version
- Associated product, system, or process
- Date range of applicability
- Key changes from previous versions
- Known limitations or issues
- Migration guidance to current documentation (where applicable)
- Downloadable files (where permitted and not restricted by licensing)

Archived documentation is provided for reference purposes only and may not reflect current capabilities, features, or procedures.
