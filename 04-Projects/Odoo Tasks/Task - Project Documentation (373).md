## Description
PVMS (Project Viability Management System) is an AI-powered tool that helps Systemaops quickly evaluate incoming RFQs from clients. When a client sends an RFQ PDF, the system extracts its content, checks it against a standard blueprint to spot missing sections, matches the project's required skills against the company's employee skill matrix to recommend the best team, and evaluates financial feasibility and risk. Based on all this, it generates a Go / Go with Caution / No-Go recommendation along with a clear list of any issues found. A manager then reviews and confirms the recommended team, after which the system generates a bid document to send back to the client.
